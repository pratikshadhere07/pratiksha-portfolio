Personal Developer Portfolio

A bespoke developer portfolio crafted with pure HTML5, modern CSS3 custom properties, glassmorphism cards, ambient neon glow aesthetics, and an accessible interactive project reporting subsystem.

Design Philosophy & Objective

Many developer portfolios rely on bloated JavaScript frameworks or off-the-shelf templates that lack distinct visual identity, inflate initial page load times, and complicate maintenance.

The objective of this project was to achieve an ultra-luxury, high-performance dark theme portfolio built on vanilla web standards. Every visual element—from ambient orbs and glowing borders to responsive grid layouts—was engineered for speed and visual impact.

Architecture & Glassmorphism System

The design system leverages CSS variables for centralized theme tokens (`--primary`, `--accent`, `--grad-main`). Translucent cards incorporate `backdrop-filter: blur(20px)` paired with multi-layer box shadows and micro-interaction keyframes.

The interactive Project Details popup provides a seamless native modal experience with keyboard focus traps, outside-click detection, and body scroll locking while keeping the code clean, modular, and lightweight.

Core Features

  • Luxury Dark Mode Aesthetics: Tailored purple, cyan, and violet gradients with glowing radial accents.
  • Interactive Project Popup Subsystem: Dynamic modal report with full responsiveness and keyboard accessibility.
  • Fluid 100% Responsive Grid: Seamlessly renders across mobile viewports, tablets, and high-DPI desktop screens.
  • Zero Bloat, High Performance: Lightweight semantic HTML with zero heavy framework overhead.
