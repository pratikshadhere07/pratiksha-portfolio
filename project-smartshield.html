Ethical Email Tracking & Cyber Threat Detection

An advanced cybersecurity platform combining forensic MIME header inspection, multi-hop web scraping, and machine learning heuristics to detect phishing, spoofed senders, and covert tracking pixels.

The Cybersecurity Challenge

Invasive email surveillance has proliferated through zero-pixel tracking beacons, obfuscated redirect chains, and deceptive phishing templates. Standard perimeter mail scanners often inspect only SPF/DKIM records without parsing the actual deep-linked payloads within the email body.

Users unknowingly reveal their IP addresses, geographic locations, device types, and opening timestamps simply by rendering emails, while advanced phishing links bypass static rule lists.

The Engineering Solution

SmartShield was designed as a dual-stage defensive forensic engine. In Stage 1, a Python-powered MIME parser dissects incoming headers, strips tracking tags, and routes every embedded URL into a sandboxed headless crawler.

In Stage 2, the crawler resolves domain age, SSL issuance records, and canonical redirects. A Scikit-Learn trained machine learning classifier evaluates these features against known malicious patterns to output a real-time Threat Probability Score.

Core Features

  • Tracking Beacon Disinfection: Automatically detects and nullifies hidden 1x1 image pixels and tracking scripts.
  • Multi-Hop Link Traversal: Unrolls URL shorteners and redirect chains to identify true destination hosts.
  • Machine Learning Phishing Classifier: Evaluates lexical, domain, and body heuristics for 96%+ classification accuracy.
  • Forensic Audit Telemetry: Generates real-time risk reports and domain provenance analytics.
